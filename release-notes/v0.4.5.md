Quick Access in groups, and a kernel Keep that keeps. **Pre-release, not yet tested on a device.**

- **Quick Access is grouped:** Live, This game, Power, CPU, Fan & battery, XeSS and Device fixes. Each group has a header you open and close with **A**; closed groups show a one-line summary (for example "15 W · boost 25 W · GPU 300–2300 MHz"). Status, pending reboots and running tasks stay at the top, and alerts with their buttons (Fix for me, Undo, Take control again) still show in a closed group. Which groups are open is remembered; This game and Power start open.
- **Kernel tab, Keep the running kernel:** now really makes the running kernel the one every power-on boots, also after a one-off "Try once" boot. Limine 12.9.5 moved its "last booted" record to a new UEFI variable and oxp3-tool read the old one, so Keep reported the stock kernel and still said Done. Bundled oxp3-tool 0.4.2 fixes it: it reads what the installed Limine uses, records the running kernel there if needed, and only says Done when that kernel boots next. The Keep button also shows when the next boot is not the running kernel.
- Needs oxp3-tool 0.4.2 (bundled; the plugin offers the update).
