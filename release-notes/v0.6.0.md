Safety and ease of use: a crash-proof panel, protected settings files, Fix all, daily update checks, a shorter **This game** group, and two opt-in extras. Bundles oxp3-tool 0.4.4. **Pre-release, not yet tested on a device.**

## New

- **Crash-proof panel**: if one part of the panel hits an error, only that part shows "This section hit an error", with **Retry** and **Copy details**. The rest of Quick Access, TDP included, keeps working. Every red problem row now has **Copy**, and **Retry** where the failed step can be run again.
- **Fix all (N)**: when two or more programs fight over power control (for example power-profiles-daemon, tuned and intel_lpmd), one confirm turns them all off. Each one still has its own **Undo**, and any that fail are listed separately.
- **Daily update checks** (Settings → **Check for updates automatically**, on by default): once a day, when no game or job is running and the device is online, OXP3 Deck checks for updates to oxp3-tool, XeSS fast mode and OXP3 Deck itself. Closed groups say **Update available**. Nothing installs on its own:
  - when the bundled oxp3-tool is newer than the installed one, tap **Install**;
  - for a new OXP3 Deck version, tap **Copy install URL**.
- **Steadier fps after loads** (Power, opt-in, off by default): with no boost value set, boost follows sustained power, at +25 % on battery and +50 % on the charger. This only shortens the burst after loading screens; it does not save battery. The details show this device's power time windows.
- **XeSS logging turns itself off**: after one game run that writes a fresh XeSS log, **Save XeSS logs** is removed from the launch options and a note says so. Turn on **Keep logging** to leave it on. While logging is on, **This game** says it costs performance.

## Changed

- **This game in Quick Access is shorter**: it keeps automatic setup, XeSS version, frame generation, problem and rollback rows, and Last run. The expert launch options (driver, compat, DX12, logs, FSR→XeSS, frame-generation multiplier, Proton, tips) are under **More for this game**, which opens the Games tab. Power is now a few presses away while you play.
- **Per-game power profiles switch in order**: when you change games quickly, only the newest switch runs. A switch that fails now shows a problem row with **Retry**, instead of failing silently.

## Fixed

- **Settings files are never silently wiped**:
  - a damaged file is set aside as `<name>.corrupt-<time>`, keeping the last 3, and Status says so;
  - automatic setup and OptiScaler records stop saving until you tap **Start fresh**, so their undo information is not lost;
  - files from a newer OXP3 Deck open read-only, and keys this version does not know are kept;
  - a read error is not treated as damage;
  - a game that still has changes applied is never dropped from the automatic setup list.
- One game exit no longer runs the after-exit steps (OptiScaler apply, XeSS log turn-off, automatic setup pass) twice at the same time, which could undo a launch-option change.

## Under the hood

- Every release and every zip build now runs the Python tests, the JS tests and the TypeScript check, and the release checks that the committed zip matches a fresh build. CI runs on every push in both repos.
