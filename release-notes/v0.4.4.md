Frame generation through OptiScaler now follows what each game actually ships. **Pre-release, not yet tested on a device.**

- **Every game:** OXP3 Deck reads the game's own files to decide which of its frame generation OptiScaler can take over, and offers only those:
  - XeSS frame generation when the game ships `libxess_fg.dll`;
  - FSR frame generation when it ships FidelityFX's frame-generation DLLs;
  - DLSS frame generation only with Streamline 2 or newer (`sl.interposer.dll`) and the game's own DLSS-FG files. Streamline 1 games (The Witcher 3, Returnal, A Plague Tale: Requiem and others) cannot use it: OptiScaler's wiki says so, and the row now says "Streamline 1: DLSS frame generation isn't possible here";
  - OptiFG (frame generation from the upscaler) always, on DirectX 12.
  The default is the first of those the game supports, in that order.
- **The Witcher 3:** the default is now the game's own XeSS frame generation (pick XeSS upscaling and XeSS frame generation in the game, borderless). This is why DLSS frame generation and Reflex stayed greyed out before. OptiFG with the wiki's HUD settings is the fallback.
- **Existing installs:** games set up automatically with an input their files rule out are moved to the right one at the next safe moment (never while the game runs, never if you changed it by hand). Hand-picked installs show **Write these choices** instead.
- Details on each game list the files and versions found and why each input is or is not offered.
