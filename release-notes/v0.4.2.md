OptiScaler for Witcher 3. **Pre-release, not yet tested on a device.**

Witcher 3's own XeSS frame generation does not start under Proton on the ONEXPLAYER 3 (tested with every launch-option route). The SteamOS video that shows it working used OptiScaler, so OXP3 Deck can now install it per game.

- **Games tab → The Witcher 3 → Install OptiScaler for this game.** Downloads a pinned OptiScaler build (v10 nightly 2026-11-05, about 69 MB, checked against its SHA-256) once, and puts `dxgi.dll`, `OptiScaler.ini` and an `OptiScaler/` folder into `bin/x64_dx12` as your user. Installing stops if the folder already has a `dxgi.dll` or another OptiScaler; the game's own files are not touched. **Remove** takes out exactly what was added and puts the launch options back.
- Choices: upscaler XeSS or FSR 3.1, frame generation Off or XeSS 2x, and which game setting OptiScaler replaces (the game's DLSS frame generation by default).
- The launch options are set for this route: `XESS`, `FSR`, `FSR_FG` and `force_vk_vendor` come out; `WINEDLLOVERRIDES=dxgi=n,b`, `XESS_FG=2` and `-dx12` go in.
- Needs an unpacker on the system: on CachyOS `sudo pacman -S 7zip` (Bazzite usually has bsdtar).
- In the game: Borderless, **DLSS** upscaling and **DLSS Frame Generation** on, then restart the game once.

OptiScaler (GPL-3.0) is downloaded when you install it and is not part of this zip. The Witcher 3 settings follow OptiScaler's own wiki.
