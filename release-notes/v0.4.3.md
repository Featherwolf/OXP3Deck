OptiScaler for any game, and automatic setup. **Pre-release, not yet tested on a device.**

## Set up games automatically

One switch on the Games tab. Turn it on once and confirm what it may do; after that, OXP3 Deck sets games up by itself, only while they are not running (right after a game quits, or when it first sees it):

- **Known games** get their best known setup: launch options (for example `-dx12`, `WINEDLLOVERRIDES`, XeSS keys, dropping ones known to crash), and OptiScaler where it is known to help.
- **Other games** get only the safe parts (launch options that only help, XeSS on XMX). OptiScaler is offered, not installed.
- **Proton:** games that use XeSS or OptiScaler and sit on a Proton without the xess-xmx-linux hook (for example the system proton-cachyos) are moved to your newest GE-Proton (Proton Experimental if there is none). A Proton you picked yourself for a game is never changed.
- **Per game:** Automatic or Manual. Anything you change by hand switches that game to Manual; OXP3 Deck then leaves it alone. Every automatic change says what it did and why, with Undo.
- **Crash rollback:** if a game quits within about a minute of starting right after an automatic change, that change is undone before the next start, and the row says so.
- Never automatic: anti-cheat and online games, a file already in the game folder, a game you set up by hand.

## OptiScaler for any game

- Every Windows game on Proton gets **Install OptiScaler (experimental)**. OXP3 Deck finds the game's main program (Unreal, Unity and plain layouts; launchers and tools skipped), picks a DLL name that is not taken and sets the matching `WINEDLLOVERRIDES`.
- About 40 games documented on OptiScaler's wiki use their own folder and DLL name; OptiScaler applies its own per-game fixes for about 150 games.
- Frame generation is offered for DirectX 12 games only; DirectX 11 and Vulkan games get upscaling only.
- Refused: games with anti-cheat (EasyAntiCheat, BattlEye and others) or known online games, and Linux-native versions.
- Needs `7zip` (CachyOS: `sudo pacman -S 7zip`) or `bsdtar` to unpack OptiScaler.
