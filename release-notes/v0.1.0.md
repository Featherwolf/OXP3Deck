The first release of OXP3 Deck, a Decky Loader plugin for the ONEXPLAYER 3 on CachyOS and Bazzite. It manages oxp3-tool and xess-xmx-linux from Quick Access in Game Mode.

**Not yet tested on a real device.** Please report what works and what does not, with the plugin's log from `~/homebrew/logs/OXP3Deck/`.

## Install

In Decky's settings turn on Developer mode, then under Developer > Install Plugin from URL enter:

```
https://raw.githubusercontent.com/Featherwolf/OXP3Deck/HEAD/release/OXP3Deck.zip
```

Or download `OXP3Deck.zip` below (keep that file name) and use Install Plugin from ZIP File. `OXP3Deck.zip.sha256` is its checksum.

## What it does

- oxp3-tool: installs and updates it (oxp3-tool 0.4.1 is bundled), shows its status, applies and reverts fixes, sets the button layout and switches kernels.
- xess-xmx-linux: installs, updates and repairs XeSS on the Arc GPU's XMX cores, adopts a hand install, picks the default Mesa driver, adds the shim to system Protons, and sets per-game launch options.
- Long jobs keep running if Decky restarts, and the plugin refuses a reboot while one is still going.
